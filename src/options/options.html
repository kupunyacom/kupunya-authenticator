    How this works

    • Codes are computed locally with WebCrypto — RFC 4226 (HOTP) and RFC 6238 (TOTP).
    • Secrets are sealed with AES-256-GCM; the key comes from PBKDF2-SHA256 over your passphrase.
    • The unlocked key lives in chrome.storage.session: memory only, gone when the browser closes.
    • Touch ID unlock wraps the vault key with a secret only your fingerprint can release (WebAuthn PRF). Your passphrase always still works.
    • Filling a code runs a small script in the current tab only when you click, through activeTab.
    • The extension requests no host permissions and makes no network requests.
